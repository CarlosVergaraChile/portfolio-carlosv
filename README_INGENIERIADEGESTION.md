## Publicación a Hostinger
Este repositorio es una fuente para la **portada**, no un espejo completo del hosting.
Antes de automatizar: determinar la raíz efectiva, respaldar `index.html` y verificar el destino.
Publicar solo `index.html` y `assets/logo-ingenieria-gestion.png`; NO ejecutar sincronización que borre otros archivos.
Preservar siempre `/cartera/`, `/hys/`, `/serviteca/`, `/finanzas/`, `/equifax/` y cualquier otra aplicación.
La conexión de `cartera-staging` es independiente. Aún NO se ha habilitado despliegue automático de esta portada.
